About

Welcome to my WEB115 site, where I showcase my journey through the course and beyond. This site serves as a hub for my projects, reflections, and learning experiences in web development. Here, you'll find information about the tools I use to build my websites, as well as the various sites I will create throughout this course.

In this course, I will be utilizing a variety of tools to enhance my web development skills. Below is a list of the key tools and sites that I will be working with:

  • VS Code: A powerful code editor that provides a great environment for writing and managing code.
  • Emmet: A plugin for VS Code that allows for faster HTML and CSS coding through abbreviations.
  • GitHub: A platform for version control and collaboration, where I will host my projects and track changes.
  • Accumulus: A validator that checks my code for errors and ensures it meets HTML, CSS, JavaScript, and accessibility standards.
  • Vicunadator: The validator that checks my pages against the course standards to ensure they meet the required specifications.

Throughout this course, I will be building several sites, each serving a unique purpose. These include:

  • Personal Site: Github Pages - Hosts my work across courses and other projects.
  • Course Site: Showcases my assignments, projects, and progress in the WEB115 course.
  • Design Site: Explores my design work and creative projects.
